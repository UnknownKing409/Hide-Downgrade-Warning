A simple, lightweight mod that automatically hides Minecraft Downgrade/incompatible warning when loading worlds saved in newer versions **"Downgrading a world is not supported"**

### 🌟 Features
* ⚡ **Automatic Skip:** Skip the warning screen so you can enter your world instantly
* 🛠️ **Lightweight:** Minimal impact on startup and performance
* 💻 **Client-Side:** Works on the client side without needing server configuration

> ⚠️ **Warning:** Make Sure to backup your world before loading it in an older version of Minecraft!
